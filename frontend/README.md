# Frontend

React + Vite single-page application for the music theory learning platform.

## Stack

- **React 18** — UI library
- **Vite 5** — build tool and dev server

## Folder Structure

```
frontend/
├── public/             Static files served as-is (favicon, etc.)
├── src/
│   ├── assets/         Images, fonts, audio samples
│   ├── components/     Reusable UI components
│   └── pages/          Top-level page components (routes)
├── package.json
└── vite.config.js      (to be created)
```

## Setup

```bash
npm install
npm run dev
```

The dev server starts at http://localhost:5173 by default.
